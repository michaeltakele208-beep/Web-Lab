Hardened Header Configuration

This endpoint enforces Content-Security-Policy, nosniff, DENY, and Referrer-Policy.

Header Audit Demonstration

Inspect the HTTP response headers in your browser developer tools or test suite.

  • Content-Security-Policy: default-src 'self'; frame-ancestors 'none'; object-src 'none'
  • X-Content-Type-Options: nosniff (mitigates MIME confusion)
  • X-Frame-Options: DENY (mitigates clickjacking)
  • Referrer-Policy: strict-origin-when-cross-origin
